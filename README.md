# CCNA Networking Project

## Company Network Implementation

This project was created using **Cisco Packet Tracer** to design and implement a company network. The project demonstrates different networking concepts, configurations, routing protocols, security features, and connectivity testing.

## Technologies and Concepts

- IP Addressing
- DHCP
- DNS
- ARP
- OSPF
- RIP
- BGP
- NAT
- SSH
- Telnet
- Packet Forwarding
- Final Connectivity Testing

## Project Files

- **CCNA Project.pkt** – Cisco Packet Tracer network project
- **Company Network Implementation.pptx** – Project presentation

## Objective

The objective of this project is to understand and practically implement important networking concepts using Cisco Packet Tracer and to verify communication between different devices in the network.

## Tools Used

- Cisco Packet Tracer

## Project Outcome

The network was configured and tested using different networking protocols and services. Connectivity between network devices was verified through practical testing.
